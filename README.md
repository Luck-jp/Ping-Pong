🏓 Pong Game (Python - OOP)

A classic 2-player Pong game built using Python Turtle graphics and Object-Oriented Programming.

🚀 Features
Two-player gameplay
Paddle controls (keyboard)
Ball movement with bounce physics
Score tracking system
Increasing ball speed over time


🛠️ Tech Used
Python 3
Turtle (built-in)

▶️ How to Run
Clone the repository:
git clone https://github.com/Luck-jp/pong-game-python.git
Navigate to the folder:
cd pong-game-python
Run the program:
python main.py

🎮 Controls
Right Player:
↑ → Move Up
↓ → Move Down
Left Player:
W → Move Up
S → Move Down

📁 Project Structure

main.py → Game loop
paddle.py → Paddle class
ball.py → Ball movement and physics
scoreboard.py → Score system

📌 Project Purpose

This project was built to understand:

Object-Oriented Programming (OOP)
Multi-file project structure
Game physics and collision detection
Event handling and real-time loops
